# 「流年」页功能规格说明书

> 交接文档：本文档用于指导「流年」页面在真实 APP 中的功能实现。
> 参考原型：`yearflow_v1.html`（同目录），实现时可对照原型查看交互与视觉效果。

---

## 一、页面概述

「流年」是柴杰相册 APP 底部导航的第 2 个 Tab（首页 / **流年** / 方隅 / 视频）。页面纵向结构（从上到下）：

1. **顶部导航**：返回按钮 + 标题「流年」 + 日历按钮（占位）
2. **那年今日卡片**：展示往年同一月日的照片
3. **时光轴（圆形时间轮）**：所有照片按拍摄时间轮动播放
4. **底部导航**：与全 APP 一致，流年 Tab 高亮

页面要求：**正好填满手机屏幕**（正常屏不滚动），中央视觉元素（圆形时间轮）尽量大。

## 二、那年今日（顶部卡片）

### 2.1 功能逻辑
- 取"今天"的 **月、日**（如 8月6日），在相册中查找**去年（今年-1）同月同日**拍摄的照片。
- 若去年没有，**逐年向前回溯**（最多 5 年：今年-1 到今年-5）。
- 若 5 年内都没有，**随机选一张**照片兜底展示。
- 命中当年若有多张，随机取一张。

### 2.2 UI 规格
- 卡片：大图（高度 ≈ 28dvh，上限 235px）+ 毛玻璃圆角卡片，与首页卡片同风格。
- 图片左上角标签，三种文案：
  - 命中去年：`去年今日 · MM-DD`
  - 命中更早：`N 年前的今天`（N = 今年 - 照片年份）
  - 兜底随机：`今日无旧照 · 随机回忆`
- 图片右上角「再往前」按钮：点击后回溯年份 -1 再查；到边界（今年-5）后点击提示"已是最早可回溯的年份"。
- 图片下方信息区：照片标题（如"西湖边散步，微风正好"）、元信息（`YYYY年M月D日 · 拍摄地点`）。

### 2.3 伪代码
```
function findOnThisDay(photos, today, startYear):
  md = MM-DD(today)
  for year in [startYear ... today.year-5]:
    hits = photos where date.MM-DD == md and date.year == year
    if hits: return {year, photo: random(hits), random: false}
  return {year: null, photo: random(photos), random: true}
```

## 三、时光轴（圆形时间轮，页面主体）

### 3.1 布局结构（SVG 视口 360×360 为基准比例）
同心三层圆环 + 中央大图：

| 元素 | 半径（viewBox 单位） | 说明 |
|---|---|---|
| 最外圈细圆 | 156 | 淡灰描边，1px |
| 虚线"岁月环" | 128 | 淡赭色虚线（dash 2 6） |
| 照片点环 | 118 | 每张照片一个圆点，按时间顺序沿圆周分布，点的外侧恰好贴虚线环 |
| 月份刻度线 | 143 → 151 | 短线，3/6/9/12 月（季度节点）加长至 140→152、加粗 |
| 月份文字 | 163 | 表盘式辐射排列（见 3.3） |
| 中央相片圆 | 直径 = 圆盘 52% | 当前播放照片，圆形裁切 |

### 3.2 照片点
- 照片按拍摄时间排序后**顺时针均匀分布**在点环上（从顶部 12 点方向开始）。
- 点样式：填充 `#C99A8E`（不透明 0.8）、白色描边 1.5px、半径 7（照片 >20 张时 5）。
- **播放中的点**：填充 `#B07D6B`、白描边 2.5px、半径 9、脉冲呼吸动画（opacity 1↔0.55，1.6s）。
- 点击任意点 → 跳转到该照片并继续播放。

### 3.3 月份标注（重点视觉）
1. **四季配色**（米色底上的柔和暖调）：
   - 春（3-5月）`#7FA37E` 嫩绿 / 夏（6-8月）`#D9A66A` 暖杏 / 秋（9-11月）`#C08368` 赭红 / 冬（12-2月）`#7E9AA8` 雾蓝
   - 刻度线和月份文字同季节色（刻度透明度 0.55）。
2. **表盘式辐射排列**：文字以圆盘 12 点方向为起点，`transform: rotate(角度-90°, 文字坐标)`，像钟表刻度一样立着排布。
3. **季度节点强化**：3/6/9/12 月（春分/夏至/秋分/冬至所在月）刻度线更长更粗（2.2px）。
4. **播放联动高亮**：当前播放照片所在月份的文字加粗（700）、放大（11.5px）、红色 `#B07D6B`。

### 3.4 中央大图
- 圆形裁切，直径 = 圆盘 52%，白描边 3px + 投影。
- 切换动画：十字淡入（opacity 0.35→1 + scale 1.08→1，0.5s）。
- 底部日期胶囊：`YYYY-MM-DD`，深色半透明底。

### 3.5 轮播与控制
- **自动播放**：3 秒/张，按拍摄时间升序循环，高亮点沿圆环顺时针移动。
- 控制条（圆盘下方）：上一张 / 播放·暂停（圆形渐变按钮）/ 下一张。
- 进度文案：`第N张 / 共M张 · 照片标题`。
- **年份筛选**：圆盘上方一行 chips（全部 / 2026 / 2025 / …），按年份过滤圆盘上的照片（重新分布）。

### 3.6 尺寸自适应（重要）
- 页面 body 为 flex 纵向布局，高度 `100dvh`，`min-height` 兜底滚动。
- 圆盘尺寸 = `min(剩余宽度, 剩余高度 - 44)`，顶部预留 40px 给节气标签区；窗口变化/旋转时重算（ResizeObserver + resize + orientationchange）。

## 四、二十四节气特效

### 4.1 触发规则
- 每张照片播放时判断其所属**节气区间**；当播放照片跨入新节气（节气序号变化）时触发一次特效。
- 进入页面首次播放也会触发（作为入场特效）。
- 节气用近似日期表（每月两个，见下），真实实现建议用精确节气日期算法（每年 ±1 天）：

```
小寒1/5 大寒1/20 立春2/4 雨水2/19 惊蛰3/5 春分3/20
清明4/5 谷雨4/20 立夏5/5 小满5/21 芒种6/6 夏至6/21
小暑7/7 大暑7/23 立秋8/7 处暑8/23 白露9/7 秋分9/23
寒露10/8 霜降10/23 立冬11/7 小雪11/22 大雪12/7 冬至12/22
```

### 4.2 四季划分（传统以节气为界）
- 春：立春 → 立夏前（节气序号 2~7）
- 夏：立夏 → 立秋前（8~13）
- 秋：立秋 → 立冬前（14~19）
- 冬：立冬 → 立春前（20~23、0、1）

### 4.3 特效规格（粒子层：圆形裁剪，覆盖整个圆盘，不拦截点击，持续约 5.6s 后清除）

| 季节 | 特效 | 粒子规格 |
|---|---|---|
| 春 | **春雨**：细长雨丝斜落 | 26 条，2px 宽、14-28px 长，雾蓝渐变 `rgba(126,154,168,.7)`，倾斜 8-18°，0.6-1.1s/条 |
| 夏 | **夏阳**：暖金光晕呼吸 + 金色光尘上浮 | ① 光晕：径向渐变暖金 `rgba(232,190,120,.6)`，2.8s 呼吸（scale .9↔1.05）；② 14 颗 4px 金色光点自下而上飘（水平随机偏移 ±20px，2-3.6s） |
| 秋 | **秋枫**：枫叶摇曳飘落 | 16 片 🍁/🍂，16-28px，左右摇摆 + 旋转，2.2-4s |
| 冬 | **冬雪**：雪花轻舞飘落 | 30 朵 ❄，9-18px，左右轻摆 + 旋转，2.5-5s |

### 4.4 节气名提示
- 触发特效同时，在**圆盘顶部上方**（月份标注之上、年份 chips 之下）显示节气名胶囊（如"立秋"）。
- 胶囊样式：深色半透明底 + 毛玻璃、白字 12px、圆角 15px、字距 2px；淡入下滑出现 → 停留 → 淡出，共 2.8s。
- 位置：圆形区域顶部预留 40px 专属区，`top:4px`，水平居中；圆盘尺寸计算时扣除该区域。

## 五、视觉风格（延续全 APP 统一风格）

- 配色：
  - 背景渐变 `#EFEAE2 → #E3DDD3`，叠加暖色光斑（径向渐变 rgba(168,143,121,.20) 等）
  - 卡片 `#F5F2EC`（半透明 + 毛玻璃 backdrop-blur）
  - 主文字 `#46413B` / 次要文字 `#968D83`
  - 主色 `#A88F79`（accent）/ 强调红 `#B07D6B` / 浅 accent `#EAE1D8`
  - 边框 `#E0DAD1` / 卡片描边 rgba(255,255,255,.5)
- 字体：`-apple-system / PingFang SC / Helvetica Neue`；标题 16-17px 粗体，正文 12.5-15px。
- 圆角：卡片 18px，按钮胶囊 15-21px；阴影柔和（0 6px 22px rgba(70,65,59,.12)）。
- 底部导航：毛玻璃半透明，中央凸起「+」发布按钮（渐变 `#C99A8E→#B07D6B`），流年 Tab 图标红色高亮。
- 整体质感关键词：**米色暖调、毛玻璃、圆角、柔和阴影**（小红书/相册类风格）。

## 六、数据需求

照片数据需至少包含（原型模拟字段，真实实现由相册库提供）：

```json
{
  "id": 3,
  "date": "2025-08-06",        // 拍摄日期 YYYY-MM-DD（必填，两个功能都依赖）
  "title": "西湖边散步，微风正好",  // 照片标题/描述
  "loc": "西湖公园",             // 拍摄地点（可选）
  "url": "https://..."          // 图片地址
}
```

- 那年今日：按 `date` 的 MM-DD 与年份筛选。
- 时光轴：按 `date` 升序排列。
- 节气特效：按 `date` 查节气表。

## 七、交互细节清单（实现时逐条核对）

1. 那年今日「再往前」最多回溯到今年-5，到边界 toast 提示。
2. 轮播 3s，跨节气才触发特效（同季节多张照片不重复触发）。
3. 点击圆点跳转、上/下一张、年份筛选切换，均不中断自动播放状态（暂停后手动切换不恢复播放）。
4. 年份筛选后照片重新按时间分布在圆环上（可能变少/变密）。
5. 中央大图每次切换有淡入动画；图片加载失败显示灰色占位。
6. 特效粒子层 `pointer-events:none`，不阻挡圆点点击。
7. 圆盘随屏幕尺寸自适应，横竖屏切换后重算。
8. 节气标签区固定 40px，圆盘不与其重叠。
9. 页面整屏铺满（正常屏无滚动），矮屏允许滚动兜底。
10. 底部导航 5 项：首页 / 流年 / + / 方隅 / 视频，流年高亮。

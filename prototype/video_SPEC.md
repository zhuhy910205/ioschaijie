# 「视频」页功能规格说明书

> 交接文档：本文档用于指导「视频」页面在真实 APP 中的功能实现。
> 参考原型：`video_v2.html`（同目录），实现时可对照原型查看交互与视觉效果。

---

## 一、页面概述

「视频」是柴杰相册 APP 底部导航的第 5 个 Tab（首页 / 流年 / 方隅 / 视频）。本页采用**抖音式整屏 Feed**：每个视频占满一屏，上下滑动整屏切换，滑到哪屏自动播放哪屏。

页面整体风格与全 APP 统一：**米色暖调 + 毛玻璃**（同首页/流年），仅视频画面本身为深色。

纵向结构（页面本身不滚动，flex 布局）：

1. **顶部栏**：品牌「视频」 + 居中频道筛选三按钮 + 上传按钮
2. **整屏 Feed**（页面主体，内部滚动）
3. **底部导航**（流内布局，不遮挡 Feed）
4. **上传 Sheet**（底部弹层，按需出现）

---

## 二、顶部栏

单行布局：`品牌「视频」（左） | 频道分段按钮（水平居中） | 上传按钮（右）`

### 2.1 频道筛选（水平居中）
- 三个按钮做成**分段控制器**（.seg，连成一颗胶囊），**水平居中**固定在顶部栏中央（`position:absolute; left:50%; transform:translateX(-50%)`）：
  - `全部` / `我上传的` / `成长精选`
- 选中态：暖色渐变底（`#C99A8E → #B07D6B`）+ 白色文字 + 柔和投影；未选中：米色半透明 + 次要文字色。
- 切换频道：立即按来源过滤视频并**回到 Feed 顶部**（滚动归零、重置到第 0 屏）。

### 2.2 上传按钮
- 右侧渐变胶囊按钮（同筛选选中态渐变），点击弹出上传 Sheet（见第六节）。

---

## 三、整屏 Feed（虚拟滚动）

### 3.1 布局
- Feed 容器：`flex:1; overflow-y:auto; scroll-snap-type:y mandatory`，高度 = 视口 − 顶栏 − 底部导航。
- 每个视频一屏（.feed-item 高度 100%），`scroll-snap-align:start`，上下滑动整屏吸附（`scroll-snap-stop:always`，一屏一停）。

### 3.2 虚拟滚动（性能关键，必须实现）
- **DOM 中始终只保留当前屏 ±1 共 3 个视频**，其余位置用透明占位（.vpad，`pointer-events:none`）撑起总高度：
  - 上占位高度 = `当前index × 屏高`
  - 下占位高度 = `(总数−1−当前index) × 屏高`
  - 占位高度必须是屏高的**整数倍**，保证 scroll-snap 吸附点仍是每屏起点。
- 滚动定位：`index = round(scrollTop ÷ 屏高)`；index 变化即重渲染窗口（上/下占位 + 3 个 item），**scrollTop 像素保持不变**，视觉无跳动。
- 视频总数不设上限（数百条也只渲染 3 屏 DOM）。
- 窗口尺寸变化（旋转/分屏/字体缩放）时重新测量屏高并重渲染。
- 空态：当前频道无视频时显示提示（"这个频道还没有视频，点右上角上传试试"）。

## 四、单屏内容（.feed-item 内各元素）

| 元素 | 位置 | 说明 |
|---|---|---|
| 视频画面 | 全屏 | `<video muted loop playsinline preload="metadata">`，`object-fit:cover`，背景透明 |
| 封面兜底 | 全屏底层 | 暖色渐变或缩略图，视频未加载/失败时可见 |
| 暗角 | 全屏 | radial-gradient 边缘压暗，增强沉浸感（不拦截点击） |
| 来源角标 | 左上 | "我上传的"（accent 色）/ "成长精选"（红色），米色半透明毛玻璃底 |
| 时长 | 右上 | `M:SS`，深色半透明底白字 |
| 音量状态 | 右上（时长旁） | 🔇 / 🔊 图标，深色半透明底，随静音状态切换 |
| 标题 | 底部 | 17px 粗体白字 + 阴影 |
| 描述 | 标题下 | 13px 白字，最多 3 行（`-webkit-line-clamp:3`） |
| 标签 | 描述下 | 小胶囊（半透明白底白字），横向排布 |
| 播放环 | 中央 | 白色半透明圆 + 播放三角，当前屏播放时淡出放大 |
| 进度条 | 底部贴边 | 3px 高，`#C99A8E → #B07D6B` 渐变，接真实播放进度 |
| 操作提示 | 中央 | "轻点屏幕 开/关声音"，短暂浮现 0.9s |

底部标题/描述/标签整体在**渐变遮罩**（透明 → 深色 0.72）上，该区域 `pointer-events:none`，不挡点击。

## 五、播放逻辑（重点）

### 5.1 自动播放（静音兜底）
- 每个视频以 `muted + loop + playsinline` 创建。
- **进入 Feed 先静音自动播放当前屏**；滑到哪屏哪屏 `play()`，离屏立即 `pause()` 释放资源。
- 进度条：`ontimeupdate` 实时更新（`currentTime ÷ duration`）；循环播放。

### 5.2 轻点屏幕开/关声音
- 单击 Feed 任意区域（除底部元信息/角标外）→ 切换全局静音状态：
  - muted → unmuted：当前屏出声，右上角变 🔊，浮现"已开声音"提示
  - 再点 → 恢复静音（🔇）
- 全局同一静音状态，所有屏的图标同步。

### 5.3 iOS 自动播放限制兜底
- 首次触摸（touchend）时对当前屏视频再调用一次 `play()`（绕开 iOS 无手势不自动播的限制）。
- 实现方需真机验证 Android/iOS 行为一致。

### 5.4 视频加载失败兜底
- `onerror`：隐藏 `<video>` 元素，展示封面渐变；进度条退回**模拟播放**（0→100% 循环）。
- 弱网/离线时页面不白屏、不报错。

## 六、上传流程（底部 Sheet）

- 点击顶部"上传" → 弹出底部毛玻璃 Sheet（圆角上滑动画）：
  1. 文件选择行（虚线框，点击唤起系统文件选择，支持 MP4/MOV/WebM）
  2. 标签输入（逗号分隔，如"旅行,风景"）
  3. 拍摄时间输入（date 控件）
  4. "取消 / 上传"两个按钮
- 点"上传"：显示渐变进度条（0→100%）→ 完成后：
  - 新视频**插入列表顶部**（来源="我上传的"，标签/拍摄时间随表单）
  - 自动回到"全部"频道并滚动到第 0 屏展示新视频
  - Toast 提示"上传成功，已置顶展示"
- 上传中禁用按钮防重复提交；真实实现接入上传 API + 真实进度（xhr.upload.onprogress）。

## 七、底部导航

- 与全 APP 一致，5 项：首页 / 流年 / **+（发布）** / 方隅 / 视频。

- 视频 Tab 高亮：图标红色（`#B07D6B`）。

## 九、数据需求

```json
{
  "id": "v1",
  "title": "周末徒步的云海",       // 视频标题（必填）
  "desc": "山顶风很大，但云海太美了", // 描述

  "play_url": "https://...",     // 视频播放地址（真实实现必填）
  "thumbnail": "https://...",    // 封面缩略图（可选）
  "shoot_time": "2026-05-02",    // 拍摄日期（可选）
  "upload_time": "2026-05-02 16:20" // 上传时间（排序用）
}
```

## 十、交互细节清单（实现时逐条核对）

1. 频道切换后回到 Feed 顶部（第 0 屏）。
2. DOM 只保留当前屏 ±1，上下占位为屏高整数倍，snap 吸附行为正常。
3. 滑到新屏：旧屏视频立即 pause，新屏 play；进度条随真实播放更新。
4. 进入页面先静音自动播；单击屏幕切换全局静音（图标 🔇/🔊 同步）。
5. iOS：首次 touchend 强制 play 兜底，需真机验证。
6. 视频加载失败：隐藏 video 显示封面渐变，进度条退化为模拟循环。
7. 上传：文件选择→标签/时间→进度条→置顶插入→回顶部展示→Toast。
8. 底部导航流内布局，不遮挡 Feed；视频 Tab 红色高亮。
9. 空频道显示空态提示。
10. 旋转/窗口变化后重新测量屏高并重渲染。
